# CHRONOPHOBIA

> ## Your greatest enemy is time itself.
> A fast-paced 3D platformer developed in **4 days** for the **GMTK Game Jam 2026**, as part of a team of game designers, programmers, artists, and sound designers.

## About

You are Agent Vector, the only known survivor of an encounter with a mysterious creature capable of consuming entire realities.
Trapped in a series of alternate dimensions, you must navigate dangerous labyrinths, outrun the creature chasing you, and reach the exit before the countdown hits zero.
Time is running out. Every second counts.

## Gameplay Features

- **Time-based gameplay:** Reach the end of each level before the countdown expires.
- **Fast-paced movement:** Run, jump, double jump, slide, and wall-run your way through the labyrinth.
- **A relentless enemy:** Escape as you get hunted through alternate dimensions.
- **Atmospheric environments:** Explore mysterious dimensions with a retro-inspired visual style and soundtrack.

## Controls

| Action | Input |
|---|---|
| Movement | WASD |
| Jump / Double Jump / Wall Run | Space |
| Slide | Hold Ctrl / C |

## Built With

- **Unity** — Game engine.
- **C#** — Gameplay programming.

## Development

CHRONOPHOBIA was created during the GMTK Game Jam 2026, with a strict four-day development window.
Working under such a tight deadline meant collaborating across multiple disciplines, making quick design decisions, and prioritizing features to deliver a complete playable experience.
